# Canal de Denuncias y Consultas CONAF — MVP exploratorio

Primera maqueta funcional para explorar el Canal Institucional de Denuncias y Consultas, usando como referencia arquitectónica Gestión de Expedientes MVP v0.6.0.

## Versión

**v0.1.0 — En revisión**

## Pantallas

- Inicio
- Denuncia
- Consulta
- Seguimiento

## Alcance de esta versión

- React + Vite + React Router + Tailwind CSS 4.
- Estado en memoria mediante Context API.
- Fixtures de casos ficticios.
- Generación de códigos de seguimiento simulada.
- Sin backend, base de datos ni almacenamiento real.
- No ingresar información real o sensible.

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Principio de validación

Esta maqueta es exploratoria. Las reglas de anonimato, estados, campos, roles, flujo y confidencialidad deben validarse con Integridad, Fiscalía y Comité de Integridad antes de considerarse requerimientos definitivos.
